CNC 切削工艺参数智能推荐系统 · 智能制造

浏览器内真算

01参数推荐

输入材料、刀具、工序与质量要求，输出可执行的切削参数主方案与两套备选。 所有数值由确定性计算引擎给出，可逐项复算。

⚙
点击「生成方案」开始计算

02十条硬约束校验与自动收敛

对给定参数逐条判定 C-01 至 C-10。越限时按 先降 ap → 再降 ae → 再降 vc → 最后降 fz 的顺序迭代收敛。

⚖
填入参数后点击「校验并收敛」

03结果预测

给出表面粗糙度、刀具寿命、加工时间三项预测及 90% 置信区间。 无历史试切样本时退化为公式值并标注 LOW 置信度——这是刻意的保守设计。

📈
填入参数后点击「计算预测」

04工艺卡生成与签发

把推荐结果落成车间可执行的工艺卡。签发后锁定，内容哈希用于防篡改校验， 修改必须走变更单流程。

📋
填入信息后点击「生成工艺卡」

05回填闭环

试切后回填实测数据，按三档阈值判定偏差： Ra > 25%、工时 > 30%、寿命 > 40%。 偏差严重时冻结该材料+刀具组合并转工艺工程师。

🔄
填入实测数据后点击「判定偏差」

06知识检索

BM25 + IDF 加权查询覆盖率 + 三因子打分（相关度 0.50 / 权威度 0.35 / 时效性 0.15）。 无可靠依据时返回空结果而非硬凑——这是防止编造的关键设计。

📚
输入查询后点击「检索」

07系统能力与质量

本页是同一个系统的浏览器内实现。Python 端服务提供 HTTP API， 本页面把计算引擎移植到 JavaScript，在纯静态环境也能真实计算。
