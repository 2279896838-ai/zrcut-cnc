## 4.2 参数推荐 ZRCNC-PAR-001（writer-rec）

- 设计意图：解决"大模型直接凭记忆给参数"和"只给一套参数无法权衡"两个失败模式。
- 推荐策略：三种策略模式——**效率优先**（MRR 最大化，vc 取区间上部 0.8–1.0）、**质量优先**（Ra 余量 ≥30%，vc 取区间中部，fz 取下限）、**寿命优先**（vc 取区间下部 0–0.3，T 最大化）。
- 参数生成顺序（必须写成固定步骤）：① 由材料+刀具查 vc 区间 → ② 算 n 并受 C-01 截断 → ③ 由 Ra_req 反解 fz 上限 → ④ 由 ap/D、ae/D 上限定切深切宽 → ⑤ 算 vf → ⑥ 算 Pc 并受 C-03 校验 → ⑦ 算颤振等级 → ⑧ 输出主方案+两套备选。
- 每一步明确"调用哪个工具/哪条公式"，模型只做选择与串联。
- 给出一个完整代入示例：M1 + T3 + OP2，要求 Ra_req 1.6 μm，写出每步数值。
- 提示词全文 700–900 字。

## 4.3 预测解释 ZRCNC-PRD-001（writer-rec）

- 设计意图：解决"预测值给了但不解释、用户不知道能不能信"。
- 预测器接口约定：输入特征 8 维（材料硬度、Kc、D、z、rε、vc、fz、ap），输出 Ra_pred、T_pred、Tm_pred、Pc 及 90% 置信区间。
- 解释三段：**公式锚点**（用 3.6 节公式给出理论值作对照）、**模型偏差**（实际预测 vs 理论值的偏离方向与原因）、**可信度**（历史样本数、区间宽度）。
- 强调：模型预测与理论公式偏离超过 40% 时必须告警并降置信度。
- 示例：M2 + T5 + OP4 球头精加工，比对 Ra_th 与 Ra_pred。
- 提示词全文 600–800 字。

## 4.4 约束校验 ZRCNC-CST-001（writer-guard）

- 设计意图：解决"推荐参数越限导致撞刀、烧刀、废件"。
- 十条硬约束 C-01–C-10 逐条给：判定式、数据来源、越限时的收敛算法（写清降哪个量、降多少、迭代几次上限）、fail 时的输出格式。
- 收敛优先级：先降 ap → 再降 ae → 再降 vc → 最后降 fz（说明理由：ap 对 Pc 影响线性且对 Ra 影响小）。
- 校验器返回 JSON 的字段定义：`{checkId, constraint, passed, actual, limit, action, detail}`。
- 提示词全文 650–850 字，必须是"编排型"提示词：模型不判定，只调用 `constraint_check` 工具并据此决策。

## 4.5 工艺卡 ZRCNC-CRD-001（writer-guard）

- 设计意图：解决"推荐结果落不到车间、操作工看不懂"。
- 工艺卡 14 个必填字段表：卡号、零件名、材料代号、毛坯尺寸、工序号、工序名、机床编码、刀具代号、n、vf、fz、ap、ae、冷却方式，另加 4 个附注字段：预计工时、预计 Ra、颤振等级、首件检验要求。
- 三种导出形态：表格（Markdown）、JSON（对接 MES）、扫码二维码内容规范。
- 签发与锁定：签发后卡号锁定，修改须走变更单，不能直接改。
- 提示词全文 550–750 字。

## 4.6 回填闭环 ZRCNC-CLS-001（writer-guard）

- 设计意图：解决"推荐完就结束、模型永远不进步"。
- 回填字段：实测 Ra、实测工时、刀具磨损 VB、是否颤振、是否有异常、操作工备注、试切记录号 TR。
- 偏差判定阈值：Ra 偏差 >25%、工时偏差 >30%、刀具寿命偏差 >40% 任一命中即触发复标。
- 三档处置：**偏差正常**（仅入库）、**偏差中**（提示调整 fz 或降速 10%）、**偏差大**（冻结该材料+刀具组合的推荐，转工艺工程师，写入知识候选）。
- 回流到模型的路径：试切记录 → 特征工程 → 增量训练 → 版本对比 → 灰度发布；写明"不得在线学习，必须离线增量"。
- 提示词全文 550–750 字。

## 第9章 端到端示例库（writer-demo）

**9.1 示例总览表**：6 个示例的场景、材料、刀具、工序、考察点。
**9.2–9.7 六个完整示例**，每个必须包含：用户输入 → 路由结果 → 检索片段 → 推荐主方案+两备选（带完整数值与代入过程）→ 校验器返回 JSON → 预测解释 → 最终五段式输出 → 风险与首件要求。六个示例：
1. M1（45#钢）+ T3（φ16）+ OP2 侧铣，Ra 1.6，效率优先。
2. M2（6061）+ T2（φ12）+ OP3 型腔粗加工，效率优先。
3. M3（304）+ T1（φ10）+ OP2，质量优先，触发 C-07 MEDIUM。
4. M5（TC4）+ T5（R5）+ OP4 曲面精加工，触发 C-09 冷却约束。
5. **【已更正】M1（45#钢）+ T4（φ20）+ OP2 侧铣，触发 C-03 功率越限并走收敛。**
   - 原设定「M4+T6(φ80)+OP1 触发 C-03」经复算不成立：n=596.8、vf=358.1、Pc=0.72 kW，仅占 11 kW 的 6.5%。大直径刀具转速低、vf 低，功率反而宽裕。
   - 更正后主线：M1+T4+OP2，vc=180、fz=0.12、ap=20、ae=14 → n=2,864.8、vf=1,375.1、**Pc=12.83 kW > 11 kW 越限**；降 ae 至 10（ae/D=0.5）→ **9.17 kW** pass，MRR=275,020 mm³/min，Ra_pred 保持 0.90 μm 不受影响。
   - 考察点：C-03 功率越限 + 收敛优先级（先降 ap → 再降 ae）+ 降切深不影响 Ra。
6. 越限拒答示例：用户要求 n=12,000 r/min 加工 M1（φ16），触发 C-01 转速越限 + C-05 材料区间越限（vc=402 m/min 远超 M1 的 120–180），双重越限，拒答枚举 MACHINE_LIMIT。
**9.8 示例反例集**：3 个典型错误回答（心算数值、跳过校验、无依据推荐），并指出错在哪条规则。
