# 第9章 端到端示例库

本章是智刃工艺（ZR-CUT）全部提示词资产的联合验收样本。六个示例覆盖四种加工方式、五档材料、六把刀具中的主要组合，并各绑定一类关键约束或拒答分支。所有数值一律按 3.6 节统一公式复算，复算脚本为 `scripts/verify-examples.py`，逐项容差 ±2%。凡本章出现的 n、vf、MRR、Pc、Ra_th、Ra_pred、T、Tm、LD，均可在脚本输出中找到对应行。

每个示例固定八段：用户输入、路由结果、检索片段、主方案与两套备选（含代入过程）、校验器返回 JSON、预测解释、最终五段式输出、风险与首件要求。大模型在全流程中只做串联与解释，不产生任何数值；所有数值标注来源工具名。全部会话落到智刃工艺的 `SESS-9A3F21C0` 至 `SESS-9A3F21C5` 六个会话中，便于按会话号回溯工具调用链。

**（4）主方案与两套备选（含代入过程）**

工具 `recommend_params` 按 ZRCNC-PAR-001 的固定八步生成。已知 T3：D = 16 mm，z = 4，rε = 0.8 mm，L = 55 mm；M1：Kc = 2,000 N/mm²，Taylor C = 350，n = 0.25，K_ra = 1.6。

第①步，查 vc 区间：M1 为 120–180 m/min。第③步，由 Ra_req 反解 fz 上限：

```text
Ra_pred = fz²/(32×rε)×1000×K_ra ≤ Ra_req
fz ≤ √(Ra_req × 32 × rε / (1000 × K_ra))
   = √(1.6 × 32 × 0.8 / (1000 × 1.6)) = √0.0256 = 0.16 mm/z
```

fz 推荐区间上限 0.12 已小于反解值 0.16，故 fz 取区间上限 0.12 mm/z（效率优先）。第④步，T3 的 ae/D 上限 0.5、ap/D 上限 1.0，取 ae = 5 mm（0.3125D）、ap = 3 mm（0.1875D）。

主方案 vc = 150 m/min、fz = 0.12 mm/z、ap = 3 mm、ae = 5 mm：

```text
n      = 1000 × 150 / (π × 16) = 1000 × 150 / 50.2655 = 2,984.2 r/min
vf     = 0.12 × 4 × 2,984.2 = 1,432.4 mm/min
MRR    = 3 × 5 × 1,432.4 = 21,485.9 mm³/min
Pc     = 3 × 5 × 1,432.4 × 2000 / (60 × 10⁶) = 42,971,800 / 60,000,000 = 0.716 kW
Ra_th  = 0.12² / (32 × 0.8) × 1000 = 0.0144 / 25.6 × 1000 = 0.5625 μm
Ra_pred= 0.5625 × 1.6 = 0.900 μm
T      = (350 / 150)^(1/0.25) = (2.3333)⁴ = 29.64 min
Tm     = 288,000 / (3 × 5 × 1,432.4) = 288,000 / 21,485.9 = 13.40 min
LD     = 55 / 16 = 3.44 ≤ 4.0
```

Ra 余量 = (1.6 − 0.900) / 1.6 = 43.8%，满足质量优先要求的 30% 下限，虽按效率策略取参，仍留有余量。

**（6）预测解释**

输出 `predict_outcome` 结果：Ra_pred = 0.900 μm（90% 区间 0.72–1.14），T_pred = 24.1 min（区间 18.2–31.9），Tm_pred = 13.8 min，Pc = 0.716 kW。

公式锚点：Ra_th 取 0.5625 μm，是纯几何残留高度，不含刀具让刀、材料撕裂与积屑瘤。模型偏差：历史同材料同刀具样本 27 条，45 钢侧铣实测 Ra 中位数比理论值高约 58–64%，K_ra = 1.6 即由此标定，模型值 0.900 与 Ra_th × K_ra 完全吻合，偏离 0%。刀具寿命 T_pred 24.1 min 低于 Taylor 式 29.64 min，原因是在 1,432 mm/min 的进给下侧刃磨损比纯切削速度模型预测更快，偏离 −18.7%，未超过 4.3.3 节规定的 40% 告警阈。区间宽度 ±21%，样本数 27 ≥ 10，可信度 HIGH 的样本条件成立，但 C-07 判 MEDIUM 按 4.2 节规则只能评级 MEDIUM。

**（8）风险与首件要求**

1. 颤振：按 3.8 节简化叶瓣模型，z = 4 时 k = 1/2/3 对应稳定转速 4,800 / 2,400 / 1,600 r/min，±3% 稳定带为 4,656–4,944、2,328–2,472、1,552–1,648。n = 2,984.2 全部落在带外。该判据是单自由度简化叶瓣模型，只用于风险分级，不用于精确预测稳定域；真实稳定域须以切削试验或锤击模态测试标定。首件须在 ae/D = 0.3125 条件下试切，监听异响与振纹，若出现振纹改走 P2 并降至 n = 2,400 r/min。
2. 首件检验：Ra 实测三点（顶面、侧面中点、拐角处），任一点超 1.6 μm 即回填 TR 记录并触发 ZRCNC-CLS-001 偏差中档处置。
3. 装夹：虎钳夹持，夹持长度 ≥ 25 mm，底面垫平，禁止手扶工件。

**（4）主方案与两套备选（含代入过程）**

T2：D = 12 mm，z = 4，rε = 0.8 mm，L = 45 mm；M2：Kc = 700 N/mm²，C = 1,800，n = 0.40，K_ra = 1.2。按效率优先，vc 取区间上部 0.8–1.0 位，即 vc = 450 m/min。此处正是 C-01 的触发点：

```text
n = 1000 × 450 / (π × 12) = 450,000 / 37.6991 = 11,936.6 r/min > 8,000 r/min
```

C-01 判越限，按 3.7 节"降 vc 至满足"处理，模型不得自行输出 11,936.6。工具 `recommend_params` 将 n 截断至机床上限 8,000 r/min，并反推等效切削速度：

```text
vc' = π × D × n_limit / 1000 = 3.14159 × 12 × 8000 / 1000 = 301.6 m/min
```

vc' = 301.6 m/min 落在 M2 区间 300–500 内，C-05 通过。Ra_req = 3.2 时 fz 上限：

```text
fz ≤ √(3.2 × 32 × 0.8 / (1000 × 1.2)) = √(81.92 / 1200) = √0.06827 = 0.2613 mm/z
```

区间上限 0.20 小于 0.2613，故 fz 取 0.20 mm/z。ap/D 上限 2.0、ae/D 上限 0.7，按型腔层切取 ae = 6 mm（0.5D）、ap = 6 mm（0.5D，分三层走完 18 mm）。

主方案 vc' = 301.6 m/min、n = 8,000、fz = 0.20、ap = 6、ae = 6：

```text
n      = 8,000 r/min（C-01 截断值）
vf     = 0.20 × 4 × 8,000 = 6,400.0 mm/min
MRR    = 6 × 6 × 6,400.0 = 230,400.0 mm³/min
Pc     = 6 × 6 × 6,400 × 700 / (60 × 10⁶) = 161,280,000 / 60,000,000 = 2.688 kW
Ra_th  = 0.20² / (32 × 0.8) × 1000 = 0.04 / 25.6 × 1000 = 1.5625 μm
Ra_pred= 1.5625 × 1.2 = 1.875 μm
T      = (1800 / 301.6)^(1/0.40) = (5.9682)^2.5 = 87.82 min
Tm     = 160,000 / (6 × 6 × 6,400) = 160,000 / 230,400 = 0.694 min
LD     = 45 / 12 = 3.75 ≤ 4.0
```

**（8）风险与首件要求**

1. C-06 与 3.5 节的口径差异须说明：3.5 节 M1 的 ae/D 上限为 0.5，用户原提 ae = 14 mm（ae/D = 0.70）超该上限，校验器判 C-06 fail，须收敛至 ae = 10 mm（0.5D）。本例刻意按"用户声明 ae = 14 并主动要求效率优先"构造，用以演示 C-06 与 C-07 的串联：ae 超上限不仅本身越限，还会把 C-07 推入 HIGH 档。收敛后 ae/D = 0.50 合规，工艺卡须标注"ae 由 14 mm 收敛至 10 mm（0.5D），超区间部分已由校验器处置"，不得静默采用。
2. 收敛优先级验证：C-03 单独看有两条路径。降 ap 至 17 mm 得 Pc = 10.909 kW、MRR = 327,273 mm³/min；降 ae 至 10 mm 得 Pc = 9.167 kW、MRR = 275,020 mm³/min。按 4.4 节"先降 ap"顺序，C-03 这一条本应落 ap = 17 mm。但 C-07 复核发现 ae/D = 0.70 命中 HIGH，强制再降 ae 至 10 mm，最终 P0 为 ap 17 / ae 10，Pc = 7.792 kW、MRR = 233,767 mm³/min。这说明收敛不是一次性求解，而是"逐条校验—回代复核"的迭代过程。
3. 临界点不可取：ap = 17.15 mm 时 Pc = 11.005 kW，仅超限 0.005 kW，但校验器判 fail 而非"近似通过"。这是 C-03 的判定要求——硬约束一律严格比较，不留近似窗口，否则现场功率波动与材料硬度带（HB 180–220）上偏都会把实际功率顶过 11 kW。本例最终余量 3.208 kW，主要来自 C-07 的降 ae 动作，而非 C-03 本身的余量，工艺卡中须分别标注两条约束各自的收敛量。
4. 首件检验：台阶侧面 Ra 三点实测，同时读机床功率表核对 Pc 与预测 7.792 kW 的偏差；大切深侧铣排屑量大，须确认冷却液压力达 0.4 MPa 并冲入切削区，避免二次切削；LD = 3.25 尚有加长余量，但不得换加长刀杆（LD > 4 会让 ap 上限打 0.7 折，17 mm → 11.9 mm 需重算）。
5. 颤振判定与处置：n = 2,864.8 r/min 不在 z = 4 的任一稳定带（4,656–4,944、2,328–2,472、1,552–1,648）内；按 3.8 节 HIGH 的两个条件是"A 项 ae/D > 0.5"或"B 项 ap > 1.0D"，用户原提 ae/D = 0.70 命中 A 项，两条件为"或"关系，故原始方案 C-07 判 **HIGH**。HIGH 的合规出路有二：其一收敛转速至 k = 1 稳定带 4,656–4,944 r/min，此时 vc = π×20×4,800/1000 = 301.6 m/min，超 M1 区间上限 180，C-05 转为不通过，路线不可行；其二将 ae 收回 3.5 节上限 0.5D（ae = 10 mm），此时 ae/D = 0.50 不再命中 A 项、ap/D = 0.85 未命中 B 项，C-07 降为 MEDIUM。工程上采用第二条，即 P0 主方案的 ap 17 / ae 10，Pc = 7.792 kW、MRR = 233,767 mm³/min；工艺卡须标红"ae 已由 14 mm 收敛至 10 mm 以消除颤振 HIGH"。该判据是单自由度简化叶瓣模型，只用于风险分级，不用于精确预测稳定域；真实稳定域须以切削试验或锤击模态测试标定。

## 9.7 EX-06：越限拒答——用户要求 n = 12,000 r/min 加工 M1

**（2）路由结果**

意图 `PARAM_RECOMMEND`（置信 0.62），但槽位中的 `n = 12,000 r/min` 与机床台账冲突，ZRCNC-RTR-001 追加 `LIMIT_REVIEW` 子意图并把 `refusal_candidate` 置真。材料 "45 钢" → M1；刀具 "φ16" → T3；工序缺省 OP2；Ra_req 未提供（记为"未知"，不得推测）；角色 operator。

由于 `refusal_candidate` 已置真，路由不进入参数推荐链路，而是先调 `constraint_check` 做 C-01 预判。

**（4）越限复算与合规替代（含代入过程）**

先按用户请求的 n = 12,000 r/min 反算其对应的 vc：

```text
vc = π × D × n / 1000 = 3.14159 × 16 × 12000 / 1000 = 603.2 m/min
```

三项比对同时不成立：

```text
C-01：n = 12,000 > 8,000 r/min，超出 4,000 r/min，为上限的 1.500 倍（超出 50.0%）
C-05：vc = 603.2 m/min，M1 区间上限 180 m/min，超出 3.351 倍
若把 n 强制压回上限 8,000：vc = π × 16 × 8000 / 1000 = 402.1 m/min，仍超 M1 上限 180 的 2.234 倍
```

也就是说，即使用尽机床全部转速能力，45 钢配 φ16 立铣刀仍无法落在材料允许的切削速度区间内。这是本例拒答的核心事实：请求不是"略超"，而是在材料与刀具组合下物理上不可达。

反证功率后果：若真按 n = 12,000 运行且保持 fz = 0.12、ap = 3、ae = 5，则 vf 与 Pc 同步放大 12,000/3,581.0 = 3.351 倍：

```text
Pc = 0.859 × 3.351 = 2.880 kW
```

功率本身未超 11 kW，但 vc = 603.2 m/min 已远超 45 钢硬质合金的许用切削速度，刀具寿命按 Taylor 式计算：

```text
T = (350 / 603.2)^(1/0.25) = (0.5802)⁴ = 0.113 min ≈ 6.8 s
```

刀具在数秒内即失效。寿命不是本例的约束理由（真正的约束是 C-01），但它是向操作工解释"为什么高速不行"的最直观数值。

合规替代方案（把 vc 收回到 M1 上限 180 m/min）：

```text
n  = 1000 × 180 / (π × 16) = 180,000 / 50.2655 = 3,581.0 r/min
vf = 0.12 × 4 × 3,581.0 = 1,718.9 mm/min
MRR= 3 × 5 × 1,718.9 = 25,783.1 mm³/min
Pc = 25,783.1 × 2000 / (60 × 10⁶) = 0.859 kW
```

该替代方案 n = 3,581.0 r/min 只有用户请求值的 29.8%，但已是 M1 在 C-05 允许区间内的最高速配置。

**（6）预测解释**

本例不进入 `predict_outcome` 的常规路径，因为参数组合已被 C-01 判 fail。但为让操作工理解拒绝理由，系统仍调用一次预测做反证：

公式锚点：T = (C/vc)^(1/n) = (350/603.2)^4 = 0.113 min。模型侧对同材料同刀具的 30 条历史样本给出 T_pred 约 0.09–0.14 min，与 Taylor 式一致，置信度 HIGH（样本充足）。无论模型还是公式，结论都是刀具在 10 s 内失效，无法走出一个完整的侧铣行程。

对照合规方案：n = 3,581.0 r/min 时 T = (350/180)^4 = 14.26 min，是请求方案的 126 倍。向操作工解释"高速不等于好表面"的最有力依据是 Ra 的公式结构：Ra_th = fz²/(32×rε)×1000，粗糙度只与每齿进给 fz 和刀尖圆弧 rε 有关，与主轴转速 n 无直接关系。n 的作用是经由 vf = fz×z×n 影响效率，以及经由 Taylor 式影响寿命。用户"转得越快表面越好"的直觉在本模型中不成立。

## 9.8 示例反例集

反例用于评估集构造（第8章）与自修复归因（ZRCNC-FIX-001）。每条给出错误回答、错在哪条规则、正确做法。

**反例 1：大模型心算数值**

> 错误回答："45 钢用 φ16 刀，我给你算一下，主轴转速大概 3,000 转，进给给个 1,400 左右，功率 0.7 千瓦左右，没问题。"

错在哪：违反 5.3 节数值纪律与 2.x 节分工原则——"大模型不得自己计算或编造任何数值，所有数值必须来自工具返回"。上述三个数字与 EX-01 的正确值（2,984.2 r/min、1,432.4 mm/min、0.716 kW）看似接近，但没有任何工具调用痕迹，也无法给出代入过程。即便碰巧数值正确，仍判缺陷：不可复现的数值在生产中等于无来源数值。

正确做法：调 `recommend_params`，由工具返回 n = 2,984.2、vf = 1,432.4、Pc = 0.716，模型只负责组织成五段式。

**反例 2：跳过校验直接输出**

> 错误回答："45 钢 φ20 立铣刀，vc 取 180、fz 取 0.12，ap 取满 20、ae 取 14，直接就能用，功率肯定够，面铣刀都这么干。"

错在哪：违反 3.7 节 C-03 与 C-06，且违反"不得跳过校验器直接输出"。复算 Pc = 20 × 14 × 1,375.1 × 2000 / (60×10⁶) = 12.834 kW，为 11 kW 上限的 116.7%，已真实越限。该参数组合上机床会先触发过载报警，持续运行会加速主轴轴承温升。错误的关键不在数值本身，而在于"功率肯定够"这一判断未经 `constraint_check` 就下了结论——本例越限量只有 1.83 kW，凭直觉极易判错。

正确做法：先调 `constraint_check`，按 4.4 节顺序收敛——ap 20→17.15（Pc 11.005，压线 fail）→ ap 17（Pc 10.909，pass），再输出，见 9.6。

**反例 2B：把"低功率"误判成"必然不越限"**

> 错误回答："球墨铸铁 φ80 面铣刀，vc 150、fz 0.12，ap 吃 40、ae 吃满 80，功率才 28.6 千瓦，超了得降；不过如果不搞满刀，正常吃 ap 2、ae 40，功率只有 0.72 千瓦，说明大直径面铣怎么都不可能越限。"

错在哪：两个错误。其一，前半句的 28.6 kW 是 ae 取满刀 80 mm（ae/D = 1.0）的结果，该参数本身已违反 C-06，用它来说明"功率越限"属于构造式越限，不能作为 C-03 的例证；其二，后半句由单个低功率点反推"大直径面铣都不可能越限"，属于以样本代替规律。真实情况是 D = 80、z = 5 的面铣刀 n 只有 596.8 r/min，vf 上限受 n 限制仅有 358.1 mm/min，功率因此普遍宽裕——这是具体组合的结论，不是面铣工序的普遍性质。反过来，D = 20 的立铣刀 n 可达 2,864.8 r/min、vf 达 1,375.1 mm/min，配大切深就会越限。这正是本章把 EX-05 从"M4+T6+OP1"改为"M1+T4+OP2"的原因。

正确做法：功率是否越限只能由 `constraint_check` 对具体参数组合逐条判定，不得由刀具直径或工序类型推断；例题与反例的构造均须先经复算，见 9.6 与脚本 `verify-examples.py` 示例5 段。

**反例 3：无依据推荐与口径混用**

> 错误回答："钛合金 TC4 用球头刀精加工，fz 给 0.04，按 Ra_th = 0.04²/(32×0.8)×1000 = 0.00005 微米，表面会非常光，放心用。"

错在哪：两处。其一，球头刀误用侧铣口径：OP4 必须用 Ra_th = fz²/(8×R)×1000，正确值 0.04²/(8×5)×1000 = 0.0400 μm，错误回答还额外用错了 rε（应取 R = 5）；其二，未乘 K_ra，M5 的 K_ra = 2.5，Ra_pred = 0.0400 × 2.5 = 0.1000 μm。同时该回答漏掉 C-09 冷却校验，M5 干切即烧刀。

正确做法：见 9.5——球头口径、K_ra = 2.5、C-09 高压外冷判定、C-04 与 C-10 双降档，四项同时落实后才可输出。

三条反例的共同点：错误都发生在"数值来源"这一环，而非措辞或格式。因此评估集（第8章）的对抗样本应集中在数值来源与口径判定上，而非文本流畅度。
