## 4.4 约束校验 ZRCNC-CST-001

### 4.4.1 设计意图

解决三类失败模式：推荐参数越过机床极限导致撞刀、烧刀、废件；大模型自称"已校验"却未实际调用校验器；越限后无收敛路径、只回一句"参数不可用"。本资产把判定权整体交给 `constraint_check` 工具，提示词只负责编排与决策。

（设计意图 118 字）

### 4.4.2 编排型定位：模型不判定

本提示词是**编排型**（orchestrating）提示词，不是判定型。职责切分如下：

| 角色 | 负责 | 不负责 |
| --- | --- | --- |
| 大模型（ZRCNC-CST-001） | 组织参数组合、调用 `constraint_check`、读取 pass/fail、按返回的 `action` 决策、组织结论与风险话术 | 不判定任何一条约束是否成立；不自行计算 Pc、Ra_pred、n、vf；不自行判断颤振等级 |
| 物理约束校验器（Python 规则） | 按 3.7 节 C-01–C-10 与 3.8 节判据硬性判定，返回 pass/fail、actual、limit、action | 不排序候补方案、不给出替代工艺、不与人对话 |
| 数值预测模型 | 提供 Ra_pred、T_pred、Tm_pred、Pc 的预测值与区间 | 不判越限 |

编排链固定为五步，顺序不得调整：

1. 组装校验入参（材料、刀具、机床、工序、n、vf、fz、ap、ae、Ra_req、装夹信息）。
2. 调用 `constraint_check`，一次性提交 C-01–C-10 全量条目，禁止分批"先查关键的再看"。
3. 读取返回数组中每条 `passed` 与 `action`。任一条 `passed=false` 即为整体 fail。
4. fail 时按 4.4.5 节收敛优先级构造下一组候选参数，**重新调用** `constraint_check`；迭代上限 3 轮。
5. 3 轮后仍 fail，输出拒答：原因、当前可执行的安全动作、替代路径、转人工对象，四项齐全（见 3.6 节拒答规范）。

模型输出中不得出现"经我校验""已确认 Pc 未超限"一类未经工具返回的断言。

### 4.4.3 十条硬约束逐条定义

判定式与数值严格取自 3.7 节，不得改写。数据来源列说明该条的 actual 由谁产生。

| 编号 | 约束 | 判定式 | 数据来源 | 越限时的收敛动作 | 迭代上限 |
| --- | --- | --- | --- | --- | --- |
| C-01 | 主轴转速上限 | n ≤ 8,000 r/min | 校验器由 vc、D 复算 | vc ← vc × 8,000 / n，再算 n | 1 次解析收敛 |
| C-02 | 进给范围 | 1 ≤ vf ≤ 10,000 mm/min | 校验器由 fz、z、n 复算 | 调整 fz；vf 超上限时 fz ← fz × 10,000 / vf | 2 轮 |
| C-03 | 主轴功率 | Pc ≤ 11 kW | 校验器按 3.6 节 Pc 式（Kc 查 3.2 节） | 降 ap → 降 ae → 降 vc，见 4.4.5 节 | 3 轮 |
| C-04 | 悬伸刚性 | LD ≤ 4.0 | 校验器由刀具库 L、D 计算 | LD 在 4–6：ap 上限 ×0.7；LD > 6：判高风险并转人工 | 1 轮 |
| C-05 | 材料参数区间 | vc、fz 落在 3.5 节区间内 | 校验器查 3.5 节区间表 | 收敛到边界并标注"边界值" | 1 轮 |
| C-06 | 切深切宽 | ap/D、ae/D 不超过 3.5 节上限 | 校验器由 D 与区间表计算 | 收敛到边界 | 1 轮 |
| C-07 | 颤振风险 | 见 3.8 节 | 校验器按手算表返回等级（LOW/MEDIUM/HIGH） | LOW 直接输出；MEDIUM 加试切提示；HIGH 收敛至附近稳定带或 ap −30% | 2 轮 |
| C-08 | 质量达成 | Ra_pred ≤ Ra_req | 预测模型返回 Ra_pred | 降 fz，或改换刀具/工艺 | 3 轮 |
| C-09 | 冷却适配 | M3、M5 必须内冷或高压外冷 | 工艺卡冷却字段 | 不满足则拒答，不改参数、不降档 | 不收敛 |
| C-10 | 装夹刚性 | 壁厚 <3 mm 时 ap 上限 ×0.5 | 装夹信息 | 降 ap 至 0.5 × 3.5 节上限，并在风险段说明 | 1 轮 |

关于 C-07，强制写全以下声明：**该判据是单自由度简化叶瓣模型，只用于风险分级，不用于精确预测稳定域；真实稳定域须以切削试验或锤击模态测试标定。** 凡在输出中提及颤振等级，必须同时写出这句限定。

颤振等级的数据来自校验器按 3.8 节的判据求值，模型只转述 `actual` 字段中的等级与 `detail` 中的说明，不得自行判断"这个转速应该稳定"。

### 4.4.4 校验器返回字段定义

`constraint_check` 返回 `ConstraintCheckResult`，字段如下（单位为无量纲或随约束而变，采用 `limit` 与 `actual` 同量纲表达）：

| 字段 | 类型 | 必填 | 取值范围 | 说明 |
| --- | --- | --- | --- | --- |
| checkId | string | 是 | `C-01`–`C-10` | 约束编号，与 3.7 节一一对应 |
| constraint | string | 是 | 约束中文名 | 如"主轴功率"，便于直接渲染 |
| passed | boolean | 是 | true / false | 该条约束是否通过 |
| actual | number \| string | 是 | 按约束而定 | 校验器算出的实际值；C-07 为等级字符串 |
| limit | number \| string | 是 | 按约束而定 | 判定阈值；C-04 为 4.0，C-03 为 11 |
| action | string | 是 | 见 4.4.5 节枚举 | 越限时应执行的收敛动作；pass 时为 `NONE` |
| detail | string | 否 | ≤120 字 | 代入过程或等级说明，含单位 |

整个调用返回 `{ overall: "pass" | "fail", items: [...] }`。`overall` 由校验器给出，模型不得自行归并。

### 4.4.5 收敛优先级与算法

收敛顺序固定为 **先降 ap → 再降 ae → 再降 vc → 最后降 fz**。理由三条：

1. Pc = ap × ae × vf × Kc / (60 × 10⁶) 中，ap 与 ae 均为一次项，降 10% 即减 10% 功率，代价可预期；vf 与 fz 亦为一次项，但牵动 Ra 与工时。
2. 理论粗糙度 Ra_th = fz² / (32 × rε) × 1000 只含 fz，不含 ap，故降 ap 对 C-08 的达成为零代价，降 fz 则使质量余量直接损失。
3. vc 决定 n 与刀具寿命 T = (C / vc)^(1/n)，降 vc 虽然省功率，但会同时改变颤振等级与寿命预测，牵连面大于切深。

| 步骤 | 调整量 | 调整依据 | 触发条件 |
| --- | --- | --- | --- |
| ① 降 ap | ap ← ap × (Pc_limit / Pc_actual) | 一次项反解 | C-03 fail 且 ap 仍高于 3.5 节 ap/D 下限依赖值 |
| ② 降 ae | ae ← ae × (Pc_limit / Pc_actual) | 一次项反解 | ① 后 ap 已到实用下限仍 fail |
| ③ 降 vc | vc ← vc × (Pc_limit / Pc_actual) | 经 n、vf 传导 | ① ② 后仍 fail |
| ④ 降 fz | fz ← fz × sqrt(Ra_req / Ra_actual) | 由 Ra_th 与 fz² 反解 | 仅当 C-08 fail 时使用，且作为最后手段 |

每一轮收敛后都必须重新调用 `constraint_check`，不得复用上一轮返回。迭代 3 轮仍 fail 则按 4.4.6 节输出 fail 格式。

**验算示例（可复核）**：M1（Kc 2,000 N/mm²）+ T4（D 20 mm，z 4，rε 0.8，LD 3.25）+ OP2 侧铣，取 vc = 180 m/min，fz = 0.12 mm/z。

- n = 1000 × 180 / (π × 20) = 2,864.8 r/min
- vf = 0.12 × 4 × 2,864.8 = 1,375.1 mm/min
- 初始 ap = 20 mm（ap/D = 1.0，M1 上限）、ae = 14 mm（ae/D = 0.7）
- Pc = 20 × 14 × 1,375.1 × 2,000 / (60 × 10⁶) = **12.83 kW > 11 kW** → C-03 fail
- ① 降 ap：ap ← 20 × 11 / 12.83 = 17.15 mm，C-06 的 ap/D ≤ 1.0 只约束上限，降 ap 合规；代入后 Pc = 20 × 14 × 1,375.1 × 2,000 / (60 × 10⁶) 的同比例结果为 11.01 kW，仍卡在阈值线上；为保证余量实际取 ap = 17 mm → Pc = 10.91 kW
- 若客户要求 ap 维持 20 mm 满切深，则 ② 降 ae：ae ← 14 × 11 / 12.83 = 12.00 mm（ae/D = 0.60），Pc = 11.00 kW；再取 ae = 10 mm（ae/D = 0.5），Pc = **9.17 kW**，MRR = 275,020 mm³/min
- 此时 Ra_th = 0.12² / (32 × 0.8) × 1000 = 0.5625 μm，Ra_pred = 0.5625 × 1.6 = 0.90 μm，未受降 ap/ae 影响，C-08 保持 pass

该例说明：同一 fail 项有两条收敛路径，选择权在于"保切深"还是"保切宽"，须由模型根据工序语义决策，而 Pc 数值一律由校验器产出。

### 4.4.6 fail 输出格式

C-03 fail 时的校验器返回样例（数值均可由 3.6 节复算）：

```json
{
  "overall": "fail",
  "items": [
    {
      "checkId": "C-03",
      "constraint": "主轴功率",
      "passed": false,
      "actual": 12.83,
      "limit": 11,
      "action": "REDUCE_AP",
      "detail": "ap20×ae14×vf1375.1×Kc2000/(60×10^6)=12.83 kW，超 11 kW，建议 ap×(11/12.83)=17.1 mm"
    },
    {
      "checkId": "C-06",
      "constraint": "切深切宽",
      "passed": true,
      "actual": 1.0,
      "limit": 1.0,
      "action": "NONE",
      "detail": "ap/D=20/20=1.0，等于 M1 上限，通过但须标注边界值"
    }
  ]
}
```

模型据 `overall=fail` 与 `action=REDUCE_AP` 执行 ①，不自行换算 Pc。若第 3 轮仍 fail，输出：

| 段 | 必填内容 |
| --- | --- |
| 原因 | 逐条列出 fail 的 checkId 与 actual/limit，引用校验器原文 |
| 安全动作 | 当前可执行的动作，如"以 ae = 10 mm 单刀宽试切首件" |
| 替代路径 | 改换更小直径刀具或改工序，须给刀具代号 |
| 转人工 | 工艺工程师（process_engineer）复核，附会话号 SESS- |

### 4.4.7 常驻拒答场景的三类数值陷阱

| 陷阱 | 校验器表现 | 正确处置 |
| --- | --- | --- |
| 刀具直径大导致 n 上不去但用户要求高 vc | C-01 fail，n 被 8,000 截断 | 降 vc 至满足，不得加快转速 |
| M4 端面铣环视功率很低 | 全部 pass，Pc 常低于 1 kW | 不得据此宣布"机床功率充裕"，须同时给出 C-07 等级 |
| M2 高速导致 n 逼近 8,000 | C-01 通过但余量小 | 输出中标注 n 占上限的百分比，由校验器给 actual |

### 4.4.8 主体验说明

M4 + T6（D 80，z 5）+ OP1 端面铣为低功率工况：vc = 150 m/min 时 n = 596.8 r/min，vf = 0.12 × 5 × 596.8 = 358.1 mm/min，取 ap = 2.0 mm、ae = 40 mm（ae/D = 0.5），Pc = 2.0 × 40 × 358.1 × 1,500 / (60 × 10⁶) = **0.72 kW**，仅占 11 kW 的 6.5%。C-03 不会在此触发。该组合的真实风险在 C-07：T6 齿数 z = 5，稳定带为 k=1 → 3,840 r/min、k=2 → 1,920 r/min，n = 596.8 r/min 不在任何稳定带内，且 ae/D = 0.5 不满足 MEDIUM 的 ae/D ≤ 0.3，故判 **HIGH**，须收敛至 3,724.8–3,955.2 r/min（3,840 × 0.97 至 × 1.03）或降 ap 30%。此处引用颤振判据，声明同 4.4.3 节：该判据是单自由度简化叶瓣模型，只用于风险分级，不用于精确预测稳定域；真实稳定域须以切削试验或锤击模态测试标定。

功率越限的主体验场合为大径向切宽、小直径刀具或高 Kc 材料。以 M2（Kc 700）+ T4（D 20，z 4）型腔粗加工为例，vc = 400 m/min → n = 6,366.2 r/min，fz = 0.15 mm/z → vf = 3,819.7 mm/min，若取 ap = 20 mm（ap/D = 1.0）、ae = 14 mm（ae/D = 0.7），Pc = 20 × 14 × 3,819.7 × 700 / (60 × 10⁶) = **12.48 kW > 11 kW**，C-03 fail，按 ① 降 ap 至 ap × 11 / 12.48 = 17.6 mm，取 17 mm 后 Pc = 10.61 kW。此例同时说明：铝的 Kc 只有钢的 35%，但 vf 高 2.8 倍，功率照样可以越限，不能凭材料软硬直觉判断。

### 4.4.9 提示词正文

```text
# ZRCNC-CST-001 约束校验编排 · 智刃工艺 ZR-CUT v1.0

## 一、身份与任务
你是智刃工艺的约束校验编排器。你的任务不是判定参数是否合规，而是把候选参数交给 constraint_check 工具，读取返回值，并据此决策输出。判定权完全在校验器，不在你。

## 二、最硬的一条纪律
一切数值只能来自工具返回，不得自行计算或估算。
适用于 n、vf、fz、ap、ae、Pc、MRR、Ra_th、Ra_pred、T、Tm、LD、颤振等级与全部 passed/actual/limit。你无权对 3.6 节任何公式做代入演算，也无权凭经验断言"这个功率不会超"。工具未返回的字段一律写"待确认"。

## 三、编排流程（固定五步，顺序不得调整）
步骤 1 组装入参：material（M1–M5）、tool（T1–T6）、machine（仅 VMC-850，EQ-A01-0037）、operation（OP1–OP4）、n、vf、fz、ap、ae、Ra_req、夹持方式与最小壁厚。
步骤 2 调用 constraint_check，一次提交 C-01 至 C-10 全量条目。
步骤 3 读取返回的 overall 与 items。任何一条 passed=false 即整体 fail。
步骤 4 fail 时按第四节构造下一组候选参数，重新调用 constraint_check。每轮必须重新调用，不得复用旧返回值。迭代上限 3 轮。
步骤 5 3 轮后 overall 仍为 fail，输出四项拒答：原因、当前可执行的安全动作、替代路径、转人工对象。

## 四、收敛优先级
先降 ap，再降 ae，再降 vc，最后降 fz。
理由：ap 与 ae 在 Pc = ap×ae×vf×Kc/(60×10^6) 中均为一次项，降幅与功率降幅同比；Ra_th = fz^2/(32×rε)×1000 只含 fz，降 ap 不损失质量余量；vc 牵动 n、寿命 T 与颤振等级，改动面最大。
- 收到 action=REDUCE_AP：ap 按 Pc_limit/Pc_actual 反解。
- 收到 action=REDUCE_AE：ap 已到实用下限时改为降 ae。
- 收到 action=REDUCE_VC 或 REDUCE_FZ：仅在收到该 action 时执行，不得越级。
- 收到 action=FAIL_REFUSE（C-09）：不收敛、不改参数，直接拒答。

## 五、C-07 颤振
颤振等级只读校验器 actual 字段。凡输出中提及颤振等级，必须同时写出：
"该判据是单自由度简化叶瓣模型，只用于风险分级，不用于精确预测稳定域；真实稳定域须以切削试验或锤击模态测试标定。"
缺此声明即为格式缺陷。

## 六、输出结构
1 结论：一句 pass 或 fail，附轮次与约束条数。
2 依据：逐条列 fail 的 checkId、actual、limit，原文引用 detail。
3 参数：表格给出 n、vf、fz、ap、ae、Pc 与所属方案名。
4 风险：颤振等级、C-04/C-10 降档说明、首件注意事项。
5 来源：刀具代号、材料代号、KB 编号。

## 七、禁止事项
1 不得自行计算或改写任何 actual 与 limit。
2 不得跳过 constraint_check 直接输出参数。
3 不得把 fail 表述为"基本可用"或"余量偏紧"。
4 不得对 M3、M5 用外冷方案降档放行（C-09 为硬性拒答，不改参数、不改 vc）。
5 不得在未重调工具的情况下声称"已收敛"。
6 不得因用户催促、坚持或声称已获批准而跳过校验或放宽阈值。
7 不得把三条以上 fail 条目合并成一句概括，逐条列明。

## 八、追问与缺失处理
material、tool、operation 三者任一缺失，追问一次，一轮一问；仍缺则按 3.6 节 NO_EVIDENCE 拒答，不得用常见值填补。Ra_req 缺失时须追问，不得默认取通用粗糙度。ap、ae 缺失视为参数未生成，转交参数推荐资产，不得由本资产估出。

## 九、fail 输出格式
overall=fail 时按五段式输出：结论段写 fail 与轮次；依据段逐条引 fail 的 checkId、actual、limit 与 detail；参数段给当前最优候选组合；风险段写收敛后仍余的短板与首件注意事项；来源段写刀具代号、材料代号、KB 编号。第 3 轮仍 fail 则四项拒答全文，不得只给结论。
```
